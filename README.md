# 🎓 Алегьери

> Учебное приложение для 9 «В»: дневник, расписание, оценки и всё, что помогает держать школьные дела в одном месте.

## ✨ Возможности

### 📚 Дневник

- статусы домашнего задания: «Известно, что задано», «Задано», «О ДЗ неизвестно» и «Нет ДЗ»;
- разделы «Актуальное», «На завтра» и «На неделю»;
- связь задания с конкретной датой и уроком;
- предложения ДЗ с модерацией;
- отметка о выполнении задания и общий процент готовности.

### 🗓️ Расписание

- расписание 9 «В» на каждый учебный день;
- актуальная дата, московское время и отметки о прошедших уроках;
- расписание звонков с понедельника по пятницу;
- отмены, замены учителей и дополнительные выходные;
- календарь каникул 2026–2027.

### 📊 Оценки

- личные оценки по предметам;
- типы работ и их вес;
- средний балл после трёх оценок;
- прогноз четвертной оценки, нужные оценки для повышения и динамика;
- связь оценки с уроком и домашним заданием.

### ✏️ Принадлежности

- личный список ручек, карандашей, тетрадей и других вещей;
- отдельные тетради для подходящих предметов;
- рекомендации администратора по количеству и необходимости.

### 🧭 Координаты

- карты предметов: **важность × сложность**;
- карты учителей: **характер × как учит**;
- шкала от −20 до +20, цветовые индикаторы и SVG-иконки предметов;
- подробная карточка точки по нажатию;
- редактирование точек администратором.

## 🔐 Учётные записи

- регистрация учеников;
- роли ученика и администратора;
- защищённые серверные сессии;
- персональные принадлежности, оценки и выполнение ДЗ.

## 📱 Платформы

Приложение адаптировано для компьютеров, планшетов и телефонов. Его можно установить как PWA через браузер на Android, iOS и ПК.

## 🚀 Запуск локально

Нужен Node.js 22 или новее.

```powershell
git clone https://github.com/ilunya100000/alighieri.git
cd alighieri
npm start
```

После запуска откройте [http://localhost:4173](http://localhost:4173).

Для устройств в той же Wi‑Fi-сети используйте адрес вида `http://IP-АДРЕС-КОМПЬЮТЕРА:4173`.

## 🗄️ Данные и развёртывание

Приложение использует SQLite. В облачной версии база расположена в постоянном хранилище Railway — аккаунты и изменения не исчезают после перезапуска.
