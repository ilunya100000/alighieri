# Алегьери v1

Учебное приложение 9 В: электронный дневник, расписание с заменами и отменами, личные принадлежности и координатные карты предметов/учителей.

Автор проекта: **ilunya100000**.

## Запуск

На компьютере с Node.js 18+:

```powershell
npm start
```

После запуска откройте `http://localhost:4173`. Устройства в той же локальной сети могут открыть `http://IP-АДРЕС-КОМПЬЮТЕРА:4173`.

## Что уже работает

- четыре явных статуса домашнего задания;
- предложение ДЗ с отправкой на модерацию;
- недельное расписание, замены и отмены;
- реальные даты недели и расписание звонков с понедельника по пятницу;
- личные счётчики школьных принадлежностей;
- карты предметов и учителей по координатам от −20 до +20;
- перетаскивание точек координат мышью в режиме администратора;
- режимы ученика и администратора;
- регистрация, безопасный вход и серверные сессии;
- SQLite-база пользователей, личных данных и состояния приложения;
- отдельные тетради по подходящим предметам и админские рекомендации;
- локальная копия данных и понятный статус синхронизации;
- установка как PWA на Android, iOS и ПК.

## Настройка администратора

Пароль передаётся однократно через переменную окружения и сохраняется только в виде стойкого хеша:

```powershell
$env:ALEGIERI_ADMIN_PASSWORD = Read-Host -MaskInput "Пароль администратора"
npm run setup-admin
Remove-Item Env:ALEGIERI_ADMIN_PASSWORD
```

SQLite-база хранится в `data/alegieri.db`, а `data/state.json` используется как исходный шаблон при создании новой базы. Для внешней публикации дополнительно потребуются HTTPS, резервное копирование и ограничение публичной регистрации.
