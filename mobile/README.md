# Android · Алегьери 3.0

Android-оболочка использует тот же защищённый сайт Railway, поэтому все аккаунты, оценки, дневник и расписание синхронизируются без отдельных копий данных.

```powershell
npm install
npm run android:sync
npm run android:open
```

Android Studio откроет проект. Для публикации потребуется создать подписанный `.aab` или `.apk` через **Build → Generate Signed Bundle / APK**.

Идентификатор приложения: `ru.alegieri.school`.
