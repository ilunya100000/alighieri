# Мобильная основа Алегьери

Веб-интерфейс уже работает как адаптивная PWA: поддерживает установку на главный экран, safe-area устройств с вырезами, touch/pointer-события и офлайн-оболочку.

`capacitor.config.json` фиксирует будущий идентификатор приложения `ru.alegieri.school`. При упаковке потребуется добавить Capacitor, Android Studio и Xcode-проект, указав адрес рабочего API вместо локального `localhost`.

До публикации понадобятся отдельные подписанные сборки, push-уведомления, HTTPS-домен и набор PNG-иконок для Android/iOS.
